### `Codepoint`

> sealed newtype over Codepoint

A Unicode scalar value: `0..0x10FFFF`, excluding the surrogate range
`U+D800..U+DFFF`.
The seal is deliberate: a byte, a codepoint and a UTF-16 unit are all
integers, and mixing them silently is the classic text-processing bug.
Construct one with `from_u32` (which validates) or with an explicit cast when
the value is a known-good constant.


### `LinguaError`

> **omen** (integer values, algebraic payload)

Every way decoding UTF-8 can fail, with the byte offset of the failure.
The offset points at the **first byte of the invalid sequence**, not at the
byte that happened to break a check. That makes a diagnostic point at the
character the user typed rather than at its tail.

### `_lingua_error`

> **_lingua_error**(code: int, offset: int) -> LinguaError

Maps a raw `_lingua_scan` code to the matching `LinguaError` variant.
Parámetros
- `code`: 1 = invalid byte, 2 = truncated, 3 = overlong, 4 = surrogate,
5 = out of range, 6 = index out of range.
- `offset`: byte offset (or index) to attach to the error.


### `_lingua_scan`

> **_lingua_scan**(s: string, offset: int, cp_out: ref to u32, len_out: ref to int) -> int

Decodes the sequence that starts at `offset`, with explicit bounds.
Returns 0 on success and fills `cp_out` / `len_out`; returns the failure
class listed on `_lingua_error` otherwise. Never reads past `s.length` and
never calls `strlen`, so embedded NUL bytes are ordinary codepoints.


### `_lingua_encode`

> **_lingua_encode**(cp: u32, out: ref to byte) -> int

Encodes one codepoint into `out` (which must have room for four bytes).
Returns the number of bytes written (1..4), or 0 when `cp` is not a scalar
value (surrogate or above `U+10FFFF`).

### `decode_prefix`

> **decode_prefix**(s: string, max_codepoints: int) -> result of (list of Codepoint, int) to LinguaError

Decodes at most `max_codepoints` codepoints and reports how many bytes they
consumed.
This is the streaming primitive: a lexer can consume a prefix without

Parámetros
- `s`: the bytes to decode. Borrowed.
- `max_codepoints`: upper bound on the returned codepoints.
Retorno
`ok (list, bytes_consumed)` or `err` at the first invalid sequence.

### `utf16_length`

> **utf16_length**(s: string) -> int

### `is_surrogate`

> **is_surrogate**(cp: Codepoint) -> bool

`true` for a surrogate code unit (`U+D800..U+DFFF`).
Surrogates are not scalar values: `from_u32`, `encode` and `encode_one`
reject them. The predicate exists so a decoder can classify raw UTF-16 input.


### `is_control`

> **is_control**(cp: Codepoint) -> bool

`true` for an ISO control codepoint (`U+0000..U+001F`, `U+007F..U+009F`).
Tabs and newlines are controls; use `is_whitespace` for the text-oriented
predicate.


### `is_whitespace`

> **is_whitespace**(cp: Codepoint) -> bool

`true` for a Unicode whitespace codepoint.
Covers the Unicode `White_Space` property: ASCII space, tab/newline family,
`U+0085`, `U+00A0`, `U+1680`, `U+2000..U+200A`, `U+2028`, `U+2029`,
`U+202F`, `U+205F` and `U+3000`.


### `is_digit`

> **is_digit**(cp: Codepoint) -> bool

`true` for a decimal digit (`Nd` in Unicode, approximately).
Covers ASCII and the common decimal blocks (Arabic-Indic, Devanagari,
Bengali, Thai, fullwidth, mathematical digits). It is checked by range, so a
newly assigned digit block is not recognised until this table grows.


### `is_letter`

> **is_letter**(cp: Codepoint) -> bool

`true` for a letter (approximate Unicode `L*`).
The predicate covers the scripts the standard library is expected to handle
in practice: ASCII, Latin-1/Extended, Greek, Cyrillic, Armenian, Hebrew,
Arabic, Devanagari, Thai/Lao, Georgian, Hiragana, Katakana, Bopomofo,
Hangul, CJK and the compatibility/fullwidth letter blocks. Marks and
punctuation inside those blocks are excluded where they are well known.

### `_grapheme_extends`

> **_grapheme_extends**(c: u32) -> bool

True when `c` extends the preceding grapheme cluster.
The approximation follows UAX #29 for the common cases: combining marks,
zero-width joiners, variation selectors and emoji skin-tone modifiers extend
the previous base. Regional-indicator pairs (flags) are not merged, so a flag
counts as two graphemes.


### `grapheme_count`

> **grapheme_count**(s: string) -> int

Counts approximate grapheme clusters.
Retorno
The grapheme count for valid input, or `-1` for invalid input.
Memoria
O(n) time, O(1) memory.
Ejemplo
