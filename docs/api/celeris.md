### `hash32`

> **hash32**(data: ref to char, length: size_t) -> u32

One-shot XXH32 digest of `length` bytes at `data` with seed 0, returned as
a u32 value. `length` is in bytes; the caller guarantees the buffer really
holds at least that many bytes for the duration of the call.

> **hash3_64**(data: ref to char, length: size_t) -> u64
