### `_rpc_take_messages`

> **_rpc_take_messages**(r: ref to result of list of JsonRpcMessage to JsonRpcParseError) -> list of JsonRpcMessage

Moves a decoded batch out of its result box.
Motivo
The batch list owns its messages; `banish` on the result would free the list
buffer shallowly (leaking the messages), while `free_messages` frees it while
the box still points at it. This moves the list out and frees only the box.
Memoria
Transfers the list to the caller and zeroes the box.

### `parse_batch_items`

> **parse_batch_items**(s: string) -> result of list of JsonRpcBatchItem to JsonRpcParseError

Decodes a batch element by element, preserving per-element errors.
Unlike `parse_batch` (which returns the first error), every element gets a
`JsonRpcBatchItem` with either a message or a parse error. This is the form a
JSON-RPC server needs to answer a mixed batch.
Parámetros
- `s`: the JSON array. Borrowed.
Retorno
`ok list of JsonRpcBatchItem` (release with `free_batch_items`) or an outer
`err JsonRpcParseError` when the whole array is invalid.
