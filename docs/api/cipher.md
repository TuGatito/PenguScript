### `_concat_parts`

> **cipher__concat_parts**(parts: list of string) -> string

Concatenates the pieces of `parts` in order into one fresh string.
Motivo
The PenguScript spelling of a linear join (`for p in parts: out = "{out}{p}"`)
is quadratic, and `std.scrolls.join` is implemented the same way. This block
sums the lengths, allocates the result once and `memcpy`s each piece, so the
cost is linear in the total length and binary-safe (embedded NULs survive).
Memoria
Allocates one owned buffer of exactly the concatenated length (plus the NUL)
and returns it; the caller releases it with `banish`. The input list and its
strings are only read, never retained.


### `_byte_at`

> **cipher__byte_at**(s: string, i: int) -> int

Byte value at `i` without allocating.
Motivo
`(calling _byte_at with s, i)` materializes a fresh one-character owning string per inspected
byte, so every scan loop leaked one buffer per byte. Reading the byte through
`.data`/`.len` allocates nothing.
Memoria
Allocates nothing. `s` is borrowed. Out-of-range reads yield `0`.


### `_finish_parts`

> **cipher__finish_parts**(parts: list of string) -> string

Concatenates `parts` and releases every element and the list itself.
Motivo
`_concat_parts` copies the bytes of its input, so the caller's `parts` list
and every owned element it holds become garbage the moment the result exists.
The codecs built that list with one `parts.push` per character and then
returned the concatenation, leaking the whole working set.
Memoria
Consumes `parts`: the returned string is freshly allocated and the caller
releases it with `banish`; the input list must not be used afterwards.


### `_drop_parts`

> **cipher__drop_parts**(parts: list of string) -> void

Releases a working `parts` list without building a result.
Motivo
The scanners return `maybe none` from a dozen points once they have already
pushed characters into `parts`; every one of those exits leaked the working
set. `_drop_parts` is the release for those paths.
Memoria
Consumes `parts`: every owned element and the list buffer are released.

### `_b64_encode_raw`

> **cipher__b64_encode_raw**(data: string, url_safe: bool, padded: bool) -> string

Encodes `data` as Base64 with a pre-sized output buffer.
Motivo
The 2.0.0 encoder appended four characters at a time with string
interpolation, which is O(n²). This block computes the exact output length
once and fills one buffer. `url_safe` selects the URL alphabet (`-`/`_`),
`padded` selects the `=` padding.
Memoria
Allocates one owned string of `4*ceil(n/3)` characters; the caller releases it
with `banish`. `data` is only read.


### `_b64_decode_raw`

> **cipher__b64_decode_raw**(data: string, url_safe: bool) -> maybe string

Decodes a Base64 string with strict padding and alphabet validation.
Motivo
Decoding has to reject out-of-alphabet characters, `=` anywhere but the tail
and every padded length that is not `4k`, `4k+2` or `4k+3` -- three checks
that are clearer (and linear) in C than in a PenguScript loop that rebuilds
its accumulator.
Memoria
Allocates one owned string of `3*floor(clean/4) - pads` bytes; the caller
releases it with `banish`. `data` is only read. ASCII whitespace is ignored,
as in the 2.0.0 contract.

### `_b32_decode_raw`

> **cipher__b32_decode_raw**(data: string) -> maybe string

Decodes a padded Base32 string, rejecting misplaced padding and impossible
data lengths.
Motivo
2.0.0 only checked `len % 8 == 0`, so `"AA======AA======"` decoded two bytes
from what is not a single valid Base32 stream. Padding is only legal at the
tail, in one of the counts `{1, 3, 4, 6}` per RFC 4648, and the unused bits of
the last data character must be zero.
Memoria
Allocates one owned string of `5*floor(data/8)` bytes at most; release it with
`banish`. `data` is only read.


### `_json_escape_raw`

> **cipher__json_escape_raw**(s: string) -> string

Escapes `s` for a JSON string literal (RFC 8259 §7).
Motivo
Escaping is a byte-by-byte rewrite whose output can be six times the input;
the 2.0.0 PenguScript loop copied the accumulator on every byte. This block
sizes the output once. `"`, `\`, `\b`, `\f`, `\n`, `\r`, `\t` get their short
escapes and the remaining C0 controls become `\u00XX`, exactly as
`json.dumps` does for ASCII input.
Memoria
Allocates one owned buffer; release it with `banish`.

### `JsonValue`

> **omen** (integer values, algebraic payload)

An immutable JSON value: the PenguScript spelling of Python's `json.loads`
result tree.
Variantes
- `JvNull`: the JSON literal `null`.
- `JvBool with value`: `true` or `false`.
- `JvInt with value`: an integral number that fits an `int`.
- `JvFloat with value`: any other number, as a 32-bit `float`.
- `JvString with value`: a decoded JSON string (UTF-8, unquoted).
- `JvArray with node`: the recursive array payload.
- `JvObject with node`: the recursive object payload.

The recursive payloads travel through `JsonArrayNode` / `JsonObjectNode`
because a direct `list of JsonValue` field inside this `omen` does not
type-check on the 2.0.0 checker (finding C-2 in the Chunk 7 bug doc). Use
`json_value_items` / `json_value_pairs` to read them without naming the
wrapper.

> **cipher_json_escape**(s: string) -> string

Escapes `s` for a JSON string literal (RFC 8259 §7).
Parámetros
- `s`: the raw text to escape. Borrowed.
Retorno
An owned escaped string (without the surrounding quotes); release it with

### `_scan_string_body`

> **cipher__scan_string_body**(s: string, start: int, quoted: bool, strict: bool, endp: ref to int) -> maybe string

Scans a JSON string body (or a bare escaped run) into its decoded text.
Parámetros
- `s`: the text to scan. Borrowed.
- `start`: index of the first byte to read. When `quoted` this must be the
opening `"`.
- `quoted`: `true` to consume a quoted literal, `false` to consume `s` from
`start` to the end.
- `strict`: `true` to reject raw control bytes, malformed escapes, invalid
UTF-8 and lone surrogates; `false` for the lenient 2.0.0 behaviour.
- `endp`: receives the index just past the consumed text.
Retorno
`some text` (owned; release with `banish`) or `none` when the input is
malformed. Under `strict` a surrogate pair such as `\uD83D\uDE00` becomes one
four-byte UTF-8 code point; under the lenient mode an unpaired surrogate is
encoded on its own (CESU-8), which is the 2.0.0 behaviour.


### `json_unescape`

> **cipher_json_unescape**(s: string) -> string

Unescapes a JSON-encoded string body (translates `\"`, `\\`, `\n`, `\r`,
`\t`, `\b`, `\f`, `\/` and `\uXXXX` back to literals).
Parámetros
- `s`: the escaped text, without surrounding quotes. Borrowed.
Retorno
An owned unescaped string; release it with `banish`. The mode is lenient (the
2.0.0 contract): an unknown escape keeps the escaped character and a lone
surrogate is encoded as CESU-8. `\uD83D\uDE00` *is* combined into `U+1F600`.
Ejemplo

> **cipher_json_get_float**(m: map of string to string, key: string) -> maybe float

### `json_value_merge`

- `b`: the overriding value. Borrowed.
Retorno
An owned merged value. When either side is not an object the result is a deep
clone of `b`. Use `json_merge_patch` for the recursive RFC 7396 semantics.


### `json_merge_patch`

> **cipher_json_merge_patch**(a: JsonValue, b: JsonValue) -> JsonValue

Applies an RFC 7396 JSON Merge Patch.
Parámetros
- `a`: the target document. Borrowed.
- `b`: the merge patch. Borrowed.
Retorno
An owned patched value. A `null` member in `b` deletes the member in `a`; a

### `json_path`

> **cipher_json_path**(m: map of string to string, path: string) -> maybe string

Traverses a dotted/bracketed path through a flat JSON map.
Parámetros
- `m`: the flat JSON map produced by `parse_json`. Borrowed.
- `path`: `user.profile.name`, `users[0].name`, … Borrowed.
Retorno
`some raw` (owned) or `none`. A final string is returned unquoted; any other
final value is returned as compact JSON. Array indices are supported and
nested objects keep their braces (2.0.0 dropped the opening brace and could
not index arrays).
Ejemplo
```pengu
calling cipher.json_path with m, "users[0].name"
```
