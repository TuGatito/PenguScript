### `_gamma_mt`

> **lot__gamma_mt**(shape: float, scale: float, max_iter: int) -> maybe float

Runs one bounded Marsaglia-Tsang acceptance loop for `shape >= 1`.
Parámetros
- `shape`: gamma shape, expected `>= 1.0`.
- `scale`: gamma scale.
- `max_iter`: hard iteration cap. `0` therefore always reports exhaustion.
Retorno
`some sample` for the first accepted proposal, or `maybe none` when the cap
is reached. Exposing exhaustion as `maybe none` is what lets the regression
test prove that the old silent `scale * d` fallback is gone.


### `rand_gamma`

> **lot_rand_gamma**(shape: float, scale: float) -> float

Returns a Gamma-distributed float with `shape` (alpha) and `scale` (theta).
Parámetros
- `shape`: gamma shape `alpha`; when `<= 0.0` the result is `0.0`.
- `scale`: gamma scale `theta`; when `<= 0.0` the result is `0.0`.
Retorno
A non-negative, finite `float`.
Algoritmo
Marsaglia-Tsang for `shape >= 1`, with the Ahrens-Dieter boost for
`shape < 1`. When a bounded acceptance pass reports exhaustion the whole
sample is retried; the weave only returns an accepted sample or panics,
so it can never hand back the non-gamma `scale * d` value 2.0.0 produced
(2.1.0 fix for B1).
Ejemplo
```pengu

```

### `rand_bytes_string`

> **lot_rand_bytes_string**(n: int) -> string

Generates `n` random bytes packed into a `string`.

### `password_symbols`

> **lot_password_symbols**() -> string

Returns the ASCII symbol set offered by `rand_password`.
Retorno
A new owned `string` holding `!@#$%^&*()-_=+[]{}|;:,.<>?`.
Nota
This is a *raw* string literal, so `{` and `}` need no `chr 123` /
`chr 125` workaround (2.1.0 fix for B5). It is a weave rather than a
`const` on purpose: the code generator folds a brace-bearing `const`
into a C literal and then mistakes the braces for interpolation, so a
`const` could not be passed to another weave at all.
Ejemplo
```pengu
var sym as string is calling lot.password_symbols
defer banish sym
```
