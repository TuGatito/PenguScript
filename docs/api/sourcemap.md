### `SourceMap`

> **rune** struct

An immutable source string plus the byte offset where every line starts.
`_line_starts[0]` is always `0`; `_line_starts[i]` is the offset of the first
byte of line `i + 1`. Line `i + 1` ends at `_line_starts[i + 1] - 1` (the
`\n`) or at the end of the source for the last line.
Memoria
Owns `_source` (a private copy) and `_line_starts`. `banish map` releases
both through `derive Nexus`.

**Fields:**

- `_source` : string
- `_line_starts` : list of int


### `_sourcemap_copy`

> **_sourcemap_copy**(s: string) -> string

Returns a fresh owned copy of `s`.
Motivo
`from_source` must own its source independently of the caller's string.
Memoria
Allocates one buffer; the caller releases it with `banish` (the map does it
through `Nexus`).


### `_sourcemap_substring`

> **_sourcemap_substring**(s: string, start: int, end: int) -> string

Returns an owned copy of the byte range `[start, end)` of `s`.
Motivo
`line_text` slices a line and `SourceMap` must return an owned string even
when the range is empty. The runtime substring helper already does exactly
this; the wrapper keeps the ownership contract in one place.
Memoria
Allocates one owned buffer; the caller releases it with `banish`.
