### `find`

> **find**(node: ref to Node, query: string) -> maybe Node

Returns the first DIRECT child element of `node` whose tag equals `query`.
The returned Node wrapper is new: it owns fresh tag/text strings, so release
it with free_node (or node.free) once done. The underlying element stays
owned by its document.
