### `escape_field`

> **escape_field**(field: string, delimiter: string) -> string

Wraps a field in double quotes when it contains the delimiter, a quote, or a
line break; doubles embedded quotes (RFC 4180).
`delimiter` is matched as a whole sequence, so with `"::"` the field `"a:b"`
stays unquoted while `"a::b"` is quoted. An empty `delimiter` falls back to
`","`.


### `escape_field_rfc4180`

> **escape_field_rfc4180**(field: string, delimiter: string) -> string

Escapes a field according to standard RFC 4180 rules (alias for escape_field).


### `escape_field_backslash`

> **escape_field_backslash**(field: string, delimiter: string) -> string

Escapes a field using backslash escaping (\", \\, \n, \r) rather than doubled quotes.
Like `escape_field`, `delimiter` is compared as a whole sequence.
