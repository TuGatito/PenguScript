### `pengu_print`

### `pengu_input`

> **spark_pengu_input**(prompt: string) -> string

Prints `prompt` to stdout (flushing first) and reads one line from stdin.
Motivo
Line input needs `fgets`, `stdin` and a NUL-terminated stack buffer, none of
which are expressible in PenguScript. The trailing `\r`/`\n` strip is kept in C
because it inspects raw bytes.
Memoria
Returns a freshly allocated owned `PenguString` (empty on EOF). Release it with
`banish`. `prompt` is borrowed and never freed.
Precondiciones
A single line is limited to 4095 bytes; longer input is split across reads.

### `pengu_parse_int`

> **spark_pengu_parse_int**(s: string) -> maybe int

Parses the whole string `s` as a base-10 int32, or `none`.
Motivo
`strtoll` plus `errno`/`ERANGE` range checking is the standard, overflow-safe
way to parse an integer; the surrounding whitespace tolerance mirrors the
pre-2.0 contract. Reimplementing it digit by digit would lose the overflow
detection that C gives for free.
Memoria
Allocates a temporary NUL-terminated copy of `s` (freed before returning) and,
on success, one boxed `int32` inside the returned `maybe`. Release the `maybe`
with `banish`.


### `pengu_parse_float`

> **spark_pengu_parse_float**(s: string) -> maybe float

Parses the whole string `s` as a double, or `none`.
Motivo
`strtod` plus `errno`/`ERANGE` checking is the only correct way to accept the
full C float grammar (`1e9`, `inf`, `nan`, hex floats) with overflow detection.
Memoria
Allocates a temporary NUL-terminated copy of `s` (freed before returning) and,
on success, one boxed `double` inside the returned `maybe`. Release the `maybe`
with `banish`.


### `pengu_parse_int_radix`

> **spark_pengu_parse_int_radix**(s: string, radix: int) -> maybe int

Parses the whole string `s` as an int32 in the given radix (2–36), or `none`.
Motivo
Radix parsing needs `strtoll` with a base argument and `errno` range checking.
The pre-2.0 parser was base-10 only; generalising it in C keeps the PenguScript
bodies of `parse_int_hex`, `parse_int_bin` and `parse_int_oct` one-liners.
Memoria
Allocates a temporary NUL-terminated copy of `s` (freed before returning) and,
on success, one boxed `int32` inside the returned `maybe`. Release the `maybe`
with `banish`.
Precondiciones
`radix` outside 2–36 yields `none`. Unlike `pengu_parse_int`, the whole string
must be consumed with no surrounding whitespace.


### `pengu_panic`

> **spark_pengu_panic**(msg: string) -> void

Prints `[PANIC] <msg>` to stderr and terminates the process with exit code 1.
Motivo
A panic must reach fd 2 unbuffered and then call `exit(1)`; both are C
process-control contracts. The function never returns, which the C signature
cannot express through `declare` without an FFI symbol.
Memoria
Allocates nothing. `msg` is a caller-owned view and is not freed, because the
process is about to terminate.


### `pengu_exit`

> **spark_pengu_exit**(code: int) -> void

Flushes both streams and terminates the process with `code`.
Motivo
`exit(code)` runs the C atexit handlers after flushing stdio. Flushing
explicitly first makes the ordering deterministic for output written without a
trailing newline, which would otherwise be lost.
Memoria
Allocates nothing. The process terminates, so no PenguScript value is released.

### `range`

> **spark_range**(start: int, end_val: int, step: int) -> list of int

Builds a half-open integer progression.
Parámetros
- `start`: first value of the sequence.
- `end_val`: exclusive upper bound.
- `step`: positive increment (default `1`).
Retorno

`start < end_val` would never terminate.

### `lcm_int`

> **spark_lcm_int**(a: int, b: int) -> int

Returns the least common multiple of `a` and `b`.
Parámetros
- `a`: first integer.
- `b`: second integer.
Retorno
The non-negative LCM, computed as `|a / gcd(a, b) * b|`. `lcm_int(0, 0)` is `0`.
Ejemplo
```pengu
calling spark.lcm_int with 4, 6     # 12
```


### `pow_int`

> **spark_pow_int**(base: int, exp: int) -> int

Raises `base` to the non-negative power `exp` by binary exponentiation.
Parámetros
- `base`: the value to raise.
- `exp`: the exponent; must be `>= 0`.
Retorno
`base ** exp`. Uses `O(log exp)` multiplications. Overflow is undefined at the
edges of `int32`; debug builds trap it.
Precondiciones
`exp >= 0`.
Ejemplo
```pengu
calling spark.pow_int with 2, 10     # 1024
```
