### `range`

> **range**(start: int, end_val: int, step: int) -> list of int

Builds and returns a new list of int holding the half-open progression
start, start + step, start + 2*step, ... while the value is < `end_val`
(`step` defaults to 1; an empty list results when start >= end_val).
`step` must be positive - a zero or negative step with start < end_val
would loop forever.
