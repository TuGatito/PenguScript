### `write_sheet`

> **write_sheet**(path: string, sheet: string, header: list of string, rows: list of list of string) -> bool

Writes a workbook to `path` with one worksheet named `sheet`. The first row
holds the `header` strings (list of string), followed by one row per `rows`
entry (a list of list of string); every cell is written as a string cell.
The file is created/truncated and the workbook is finalized and closed here.
Returns true when the workbook was opened and closed cleanly, false when the
handle could not be opened (null, e.g. bad path) or xlsxio reported a close
error. Handles and byte views stay internal to the call.
