### `serve_file`

> **serve_file**(path: string) -> Response

Reads the file at `path` and wraps it in a 200 Response, guessing a
Content-Type header from the file extension (.html, .css, .js, .json, .png,
.jpg/.jpeg, .txt); unknown extensions fall back to application/octet-stream.
When the file cannot be read a 404 Response with body "File not found" is
returned instead. Files are read as UTF-8 text, so this suits text assets.

### `tcp_recv`

> **tcp_recv**(sock: ref to TCPSocket, max_bytes: int) -> maybe string

Reads up to `max_bytes` bytes from the connected socket `sock` into a fresh

message, so loop until the expected data has arrived.

### `url_encode`

inverse of url_encode for encoded input.
